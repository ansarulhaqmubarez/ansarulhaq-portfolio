# راهنمای مدیر سایت CineCode (بدون کدنویسی)

## الف) راه‌اندازی اولیه (فقط یک بار)
1. وارد Supabase شو ← SQL Editor.
2. فایل‌های SQL را به این ترتیب اجرا کن (هر کدام: New query ← چسباندن ← Run): `cms-2` ← `cms-3` ← `cms-4` ← `cms-5` ← `cms-6` ← `cms-7`. اجرای دوباره ضرر ندارد.
3. حساب خودت را مدیر کل کن: `update public.profiles set role='super_admin' where email='ایمیل-تو';`
4. پوشهٔ سایت (محتوای زیپ) را در Cloudflare آپلود کن.
5. در مرورگر `Ctrl+Shift+R` بزن.
6. وارد ادمین شو ← «بررسی پیش از انتشار» ← اجرا. هر ✗ را طبق توضیح زیرش درست کن.
7. در بخش پروژه‌ها، گالری و رزومه دکمهٔ «Import» را یک بار بزن.

## ب) کارهای روزمره
- **متن‌های سایت:** ادمین ← ویرایش متن‌ها.
- **پروژه‌ها و گالری:** ادمین ← استودیو.
- **رزومه:** ادمین ← رزومه.
- **دوره‌ها و درس‌ها:** ادمین ← دوره‌ها (ویدیوها از یوتیوب).
- **دانشجویان:** ادمین ← دانشجویان (جستجو، CSV).
- **گواهی‌ها:** ادمین ← گواهی‌ها (صدور، ابطال).

## ج) ظاهر و جلوه‌ها (ادمین ← ظاهر و جلوه‌ها)
همه خودکار ذخیره می‌شوند. بالای بخش «پیش‌نمایش زنده» هست.
1. **افکت‌ها:** هر کدام یک تیک (اسلوگن تایپی، کج‌شدن کارت‌ها، پرده‌ی انتقال، …).
2. **رنگ اصلی:** ۶ رنگ آماده.
3. **قالب گواهی و رزومه:** قالب پیش‌فرض را انتخاب کن.
4. **چیدمان صفحهٔ اول:** با ✓ نشان بده/پنهان کن، با ↑ ↓ جابه‌جا کن.
5. **منوی بالا:** پنهان، تغییر نام، ترتیب، تا ۶ لینک اضافه.
6. **لینک‌های فوتر**، **مشخصات و امضای گواهی**.
7. **پرسش‌های پرتکرار** (صفحهٔ آکادمی)، **مدرس‌ها و تیم**، **نظرات دانشجویان**، **شریک‌ها**، **تازه‌ها و اخبار**.
8. **بنر اعلان** (با شمارش معکوس اختیاری).
9. **فرم خبرنامه:** روشن کن؛ ایمیل‌ها در ادمین ← خبرنامه.
10. **ساخت بخش جدید:** متن، بنر، نقل‌قول، تصویر+متن.

## د) پشتیبان‌گیری
ادمین ← پشتیبان‌گیری: «دانلود» قبل از تغییر بزرگ؛ «بازیابی» برای برگرداندن.

## هـ) اگر مشکل پیش آمد
- تغییری دیده نمی‌شود: `Ctrl+Shift+R`.
- ذخیره نمی‌شود: ✗ «ذخیرهٔ تنظیمات» در بررسی؛ `cms-6.sql` را اجرا کن و با حساب مدیر کل وارد شو.
- ایمیل نمی‌رود (خطای 504): پورت SMTP را 587 بگذار یا از Brevo استفاده کن. رمز اپلیکیشن Gmail که در چت فرستاده شد را عوض کن.
